# Лабораторная работа №1: Матрицы комплексных чисел

## Описание
Класс для работы с матрицами комплексных чисел. Реализованы операции:
- Сложение матриц
- Умножение матриц
- Деление матриц (через обратную матрицу)
- Транспонирование
- Вычисление определителя

## Структура проекта
- `Complex.java` — класс комплексного числа
- `ComplexMatrix.java` — класс матрицы комплексных чисел
- `Main.java` — консольный интерфейс

## Как запустить
1. Убедитесь что установлен JDK 17+
2. Откройте папку проекта в VS Code или IntelliJ IDEA
3. Запустите Main.java
4. Используйте меню для выбора операций
